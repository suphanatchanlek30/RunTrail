## สี

### สีแบรนด์

สีเหล่านี้เหมือนกันทั้งโหมดกลางวันและกลางคืน

| ชื่อ | สี | ใช้กับ |
|---|---|---|
| Green | `#00D47A` | ปุ่มหลัก · เส้นทาง · สถานะสำเร็จ |
| Lime | `#A3F51F` | ไฮไลต์บนพื้นดำ · วงแหวนกดค้างเพื่อจบ |
| Ink | `#0F1412` | การ์ดสรุป · ปุ่มเริ่มวิ่ง · ชิปที่เลือก |

### สีพื้นและตัวอักษร

| ชื่อ | กลางวัน | กลางคืน | ใช้กับ |
|---|---|---|---|
| Surface | `#FFFFFF` | `#161C19` | การ์ด · Bottom sheet |
| Canvas | `#F5F7FA` | `#0B0F0D` | พื้นหลังหน้าจอ |
| Text | `#0B0F17` | `#F2F5F3` | ข้อความหลัก |
| Text tertiary | `#667085` | `#97A39D` | ข้อความรอง |
| Border | `#E4E7EC` | `#2C3530` | เส้นขอบ |

### สีสถานะ

| ชื่อ | สี | ใช้กับ |
|---|---|---|
| Danger | `#E5484D` | ลบ · ข้อผิดพลาด |
| Warning | `#E59A0B` | รอซิงก์ · คำเตือน |

## ตัวอักษร

| ฟอนต์ | ใช้กับ |
|---|---|
| **Anuphan** | หัวข้อและตัวเลขใหญ่ |
| **IBM Plex Sans Thai** | เนื้อหา ปุ่ม และป้ายกำกับ |

| สไตล์ | ขนาด | ใช้กับ |
|---|---|---|
| Display | 48 | ตัวเลขใหญ่สุด เช่น ระยะทาง |
| H1 / H2 / H3 | 28 / 22 / 18 | หัวข้อหน้าและหัวข้อย่อย |
| NumL / NumM | 24 / 18 | ตัวเลขในไทล์สถิติ |
| BodyL / Body / BodyS | 16 / 15 / 14 | เนื้อหา |
| LabelL / LabelM / LabelS | 15 / 14 / 12 | หัวการ์ด ปุ่ม ป้าย |
| Caption / Overline | 12 / 11 | คำอธิบายเล็ก หัวกลุ่ม |

## รูปทรงและคอมโพเนนต์

| สิ่งที่ใช้ | ค่า |
|---|---|
| มุมโค้ง | ช่องกรอก 14 · ปุ่ม 16 · การ์ด 20 · Bottom sheet 28 (dp) |
| ปุ่มหลัก | สีเขียว สูง 54 dp |
| ปุ่มไอคอน | วงกลม 44 dp |
| ชิปตัวกรอง | เลือกอยู่เป็นสีดำ |
| สวิตช์ | 46 × 28 dp วาดเองใน `ToggleSwitch` |
| ไอคอน | [Lucide](https://lucide.dev) แบบเส้น |
