## ความเป็นส่วนตัวและความปลอดภัย

### บัญชีและ token

- รหัสผ่านเก็บแบบ hash ด้วย **argon2id**
- access token อายุ 15 นาที · refresh token เปลี่ยนใหม่ทุกครั้งที่ใช้ ถ้ามีการใช้ซ้ำจะยกเลิกทั้งชุด
- token ในเครื่องเข้ารหัส **AES-GCM ด้วยกุญแจใน Android Keystore** และไม่ถูกสำรองไปเครื่องอื่น

### ข้อมูลการวิ่ง

- ทุกคำขอตรวจว่าเป็นเจ้าของข้อมูล การส่งการวิ่งด้วย UUID ของคนอื่นถูกปฏิเสธ
- หน้าเว็บแชร์ **ซ่อนจุดในรัศมี 200 ม. รอบจุดเริ่มและจุดจบ** ตัดที่เซิร์ฟเวอร์ จุดเหล่านี้จึงไม่ถูกส่งออกไปเลย
- หน้าเว็บแชร์ไม่เปิดเผยเวลาของแต่ละจุด

### ระบบ

- ที่เก็บรูปไม่เปิดสาธารณะ เข้าถึงผ่านลิงก์ชั่วคราว (presigned URL) เท่านั้น
- build ที่ใช้จริงต่อเซิร์ฟเวอร์ผ่าน HTTPS เท่านั้น HTTP อนุญาตเฉพาะ build debug
- ไฟล์ลับ (`.env`, key, keystore) ไม่ถูกเก็บใน git

## สิทธิ์ที่แอปขอ

แอปอธิบายเหตุผลก่อนขอสิทธิ์ทุกครั้ง และใช้งานส่วนอื่นได้แม้ไม่ให้บางสิทธิ์

| สิทธิ์ | ใช้ทำอะไร |
|---|---|
| `ACCESS_FINE_LOCATION` · `ACCESS_COARSE_LOCATION` | บันทึกเส้นทางและวัดระยะ (จำเป็นสำหรับการวิ่ง GPS) |
| `FOREGROUND_SERVICE` · `FOREGROUND_SERVICE_LOCATION` | บันทึกต่อเนื่องขณะปิดจอ |
| `ACTIVITY_RECOGNITION` | อ่าน Step Counter เพื่อคำนวณ Cadence |
| `POST_NOTIFICATIONS` | สถานะการวิ่ง · เพซทุก 1 กม. · สถิติและอันดับ · เตือนไปวิ่ง |
| `INTERNET` · `ACCESS_NETWORK_STATE` | โหลดแผนที่และซิงก์กับเซิร์ฟเวอร์ |
| `SCHEDULE_EXACT_ALARM` | เตือนไปวิ่งตรงเวลา ถ้าไม่อนุญาตจะเตือนช้าได้ไม่เกิน 10 นาที |
| `RECEIVE_BOOT_COMPLETED` | ตั้งเวลาเตือนกลับหลังเปิดเครื่องใหม่ |
| `WRITE_EXTERNAL_STORAGE` | บันทึกภาพแชร์ลงแกลเลอรี (Android 9 เท่านั้น) |
| `ACCESS_LOCAL_NETWORK` | ต่อเซิร์ฟเวอร์ในวง Wi-Fi บน Android 17 (build debug เท่านั้น) |

เซนเซอร์ทุกตัวประกาศเป็น `required="false"` เครื่องที่ไม่มีบางตัวก็ติดตั้งและใช้งานได้
